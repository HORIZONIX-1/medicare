# Pull Request

##  PR Title Format

Please use the following format for your PR title:

```text
type(scope): short-description
```

**Examples:**
- `feat(auth): add google authentication`
- `fix(api): resolve token validation issue`
- `docs(readme): update installation guide`
- `refactor(database): optimize query handling`

##  Pull Request Checklist

Before submitting this PR, please confirm:

- [ ] PR title follows the required format
- [ ] Code follows project conventions
- [ ] No unnecessary files included
- [ ] Latest changes pulled from `main`/`develop`
- [ ] No merge conflicts
- [ ] Changes tested properly
- [ ] Documentation updated if required
- [ ] Screenshots added for UI changes

##  Contribution Guidelines

To maintain a clean and scalable codebase:
- Keep PRs focused on a single feature or fix
- Avoid unrelated changes in one PR
- Write meaningful commit messages
- Follow branch naming conventions
- Test changes before requesting review
- Keep code readable and maintainable
