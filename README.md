# 🏥 Horizonix Medicare System

A modern healthcare management system developed for **Hope Medical Center**. Horizonix Medicare System is designed to simplify hospital operations by providing an efficient, secure, and user-friendly platform for managing patients, appointments, medical records, staff, and other healthcare services.

---

## 📖 About the Project

Horizonix Medicare System is a full-stack web application built to improve the daily workflow of Hope Medical Center. The system provides a centralized platform for healthcare professionals and administrators to manage medical information efficiently while ensuring data security and reliability.

---

## ✨ Features

- 👤 Patient Management
- 📅 Appointment Scheduling
- 🩺 Doctor Management
- 📋 Medical Records Management
- 💊 Prescription Management

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/horizonix-medicare-system.git
cd horizonix-medicare-system
```

---

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

The frontend will start on:

```
http://localhost:3000
```

---

## Backend Setup

```bash
cd server
npm install
npm run dev
```

The backend server will start on:

```
http://localhost:5000
```
